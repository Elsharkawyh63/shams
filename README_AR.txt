Sama Birthday Quiz — V12 WebP

1. فك الضغط وانسخ index.html إلى مشروعك الأصلي بجانب مجلد frames.
2. حوّل جميع الفريمات إلى WebP مع الحفاظ على الخلفية الشفافة وأبعاد ومواقع الشخصية الأصلية.
3. استبدل PNG بملفات WebP بنفس الأسماء والأرقام داخل نفس المجلدات. مثال:
   frames/00_intro_peek/001.webp ... 088.webp
   frames/01_walk_in/001.webp ... 080.webp
   frames/02_point_down/001.webp ... 080.webp
   frames/03_sit_down/001.webp ... 080.webp
   frames/04_sitting_idle/001.webp ... 080.webp
   frames/05_introduction/001.webp ... 080.webp
   frames/06_wrong_reaction/001.webp ... 080.webp
   frames/07_correct_reaction/001.webp ... 080.webp
4. شغّل index.html من نفس المجلد؛ لا تحتاج تغيير مسارات الصور.
5. نفس 10 أسئلة وإجاباتها والـScroll التدريجي والرياكشنات محفوظة.
6. النصوص الخمسة متطابقة مع آخر تعليمات المستخدم ولا توجد عناوين مشاهد إنجليزية.

مهم: تغيير امتداد الملف فقط لا يحوّله إلى WebP. احرص على التحويل الفعلي، وWebP لا يرفع دقة صورة PNG تلقائيًا؛ حدد جودة الضغط المناسبة.
إذا كان عدد الفريمات مختلفًا، غيّر count داخل CONFIG في index.html.
